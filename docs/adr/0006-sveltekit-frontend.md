# SvelteKit for the frontend

The web app uses SvelteKit with Svelte 5. We ranked learning something new first and stability second; SvelteKit is new to us, stable, and its built-in transitions and `animate:flip` suit card movement. We rejected Solid with TanStack Start because Solid support there is beta and tied to the Solid 2.0 beta, Nuxt because it offers little new to learn, and a separate Astro site for the shop because the shop needs the game's auth sessions and card components.
